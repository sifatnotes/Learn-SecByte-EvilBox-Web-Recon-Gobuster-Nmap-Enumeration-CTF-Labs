# Learn SecByte EvilBox Web Recon, Gobuster, Nmap & Enumeration CTF Labs

Hands-on cybersecurity and CTF lab collection focused on EvilBox web reconnaissance, hidden-path discovery, Gobuster, Nmap, HTTP analysis, web fingerprinting, service enumeration, port probing, exposed code, and upload-security concepts.

These labs are suitable for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners practicing authorized security testing.

## Introduction

This collection covers practical reconnaissance and enumeration techniques commonly used during security assessments.

The labs progress from basic web discovery and exposed resources to automated directory enumeration, web fingerprinting, service identification, port reconnaissance, and host discovery.

Use these exercises only against intentionally vulnerable or explicitly authorized systems.

## Learning Path

A practical progression through the collection is:

1. Start with **Nmap Host Reconnaissance** to understand basic host discovery.
2. Continue with **PortProbe EvilBox One** for port reconnaissance.
3. Explore **EvilBox Service Sleuth** to identify available services.
4. Move into **Evil HTTP Trail** and **Shadow Recon** for web reconnaissance.
5. Study **Robots in Plain Sight** for information-disclosure discovery.
6. Practice hidden-resource enumeration with **Secret Path Recon** and **Shadow Path Discovery**.
7. Use **Gobuster Trail: Find Hidden Web** for directory and path enumeration.
8. Study **Blind Side EvilBox Web Fingerprint** to practice web fingerprinting.
9. Finish with **Evil Code Exposed** and **Upload Trap Fundamentals** to examine additional web-security weaknesses.

## How to Use the Labs

1. Select a lab from the direct-link index.
2. Confirm that the target is an authorized training environment.
3. Read the objectives and define the testing scope.
4. Perform reconnaissance before attempting exploitation.
5. Document discovered hosts, ports, services, technologies, paths, and application behavior.
6. Use tools such as Nmap or Gobuster only against permitted targets.
7. Record your methodology and findings.
8. Review defensive recommendations after completing each exercise.
